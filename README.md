# สูตรหวยลาว 10 สูตร

หน้าเว็บคำนวณเลขหวยลาวงวดถัดไปจาก 10 สูตร พร้อมผลย้อนหลังของแต่ละสูตร

- `index.html` หน้าเว็บ (คำนวณทั้งหมดในเบราว์เซอร์)
- `draws.json` ผลหวยลาวพัฒนาตั้งแต่ 2 ม.ค. 2569 อัปเดตอัตโนมัติทุกคืน

ทุกสูตรคำนวณจากผลของงวดก่อนหน้าเท่านั้น ผลย้อนหลังไม่ได้บอกว่างวดหน้าสูตรไหนจะเข้า ใช้ดูสถิติเท่านั้น
